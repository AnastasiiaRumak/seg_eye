# seg_eye

Этот код представляет несколько подходов к обработке изображения глаза с целью сегментации различных структур (зрачка, радужной оболочки) с использованием различных методов компьютерного зрения.

## Основные функции и методы

### 1. Анализ гистограммы
- Загрузка изображения в оттенках серого
- Построение и визуализация гистограммы распределения интенсивности пикселей
- Определение пороговых значений для сегментации на основе анализа гистограммы

### 2. Пороговая сегментация
- Применение нескольких пороговых значений для выделения различных областей
- Создание бинарных масок для сегментации текстуры
- Визуализация результатов сегментации

### 3. Автоматическое определение порогов
- Вычисление оптимальных пороговых значений на основе распределения пикселей
- Использование кумулятивной суммы гистограммы для нахождения точек разделения
- Применение морфологических операций (закрытие и открытие) для улучшения результатов бинаризации

### 4. Обнаружение окружностей методом Хафа
- Реализация функции `find_pupil_and_iris` для обнаружения круглых структур
- Настройка параметров для поиска окружностей определенного радиуса
- Визуализация найденных окружностей с информацией о центре и радиусе

### 5. Сравнение методов бинаризации
- Применение различных методов бинаризации:
  - Метод Оцу
  - Адаптивная бинаризация
  - Бинаризация по V-каналу в HSV-пространстве
- Сравнение и визуализация результатов разных методов

### 6. Анализ корреляции и поиск контуров
- Применение операции макс-пулинга для уменьшения размерности изображения
- Вычисление коэффициента корреляции Пирсона между исходным и обработанным изображением
- Поиск и визуализация контуров на изображении

## Используемые библиотеки
- OpenCV (cv2) - для работы с изображениями
- NumPy - для численных операций
- Matplotlib - для визуализации
- Scikit-image - для расширенных операций с изображениями
- SciPy - для статистического анализа
